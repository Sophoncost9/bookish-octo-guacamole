# PHISO Shop Drawing: ฐานราก → Shop Drawing + Bar Cutting List + 3D

งานนี้คือการเอาแบบขยายฐานรากจากผู้ออกแบบ มาทำเป็นเอกสารที่ช่างตัด-ดัดเหล็กหยิบไปทำงานได้ทันที โดยต้องมี:
1. **Shop Drawing**: แปลนเหล็กเสริมและรูปตัด A-A พร้อมเส้นบอกระยะ, Mark, ระยะหุ้ม และหมายเหตุ
2. **Bar Cutting List (BBS)**: แต่ละ Mark มีขนาด รูปดัด ระยะ ยาวตัด จำนวนท่อน และน้ำหนัก โดยปรับจำนวนฐานได้
3. **แผนตัดเหล็กเส้น 10 ม.**: บอกว่าแต่ละเส้นตัดได้กี่ท่อน เหลือเศษเท่าไร และต้องสั่งเหล็กกี่เส้น
4. **โมเดล 3 มิติ**: เปิด/ปิดคอนกรีตหรือเหล็กแต่ละ Mark ได้ แตะเหล็กแล้วขึ้นยาวตัด
5. **ปริมาณงานอื่น**: ดินขุด ทราย คอนกรีตหยาบ คอนกรีต แบบหล่อ และลวดผูก
6. **Excel** สำหรับช่าง: กรอกจำนวนฐานที่ช่อง C3 แล้วสูตรคำนวณยอดรวมกับจำนวนเหล็กที่ต้องสั่งให้เอง

ทุกอย่างสร้างจาก script ตัวเดียว ตัวเลขในหน้าเว็บกับ Excel จึงตรงกันเสมอ

## ขั้นตอน

### 1. อ่านแบบแล้วเขียน config JSON
อ่านค่าจากแบบ ทั้งแปลนและรูปตัด แล้วเขียนไฟล์ config ตามตัวอย่าง `examples/F1.json` ซึ่งได้มาจากแบบจริง (ฐาน 1.00×1.00×0.25 ม., 10-DB12 B1/B2, RB9 รัดรอบ)

| คีย์ | ความหมาย (หน่วย มม.) |
|---|---|
| `footing.B / L / t` | กว้าง X / ยาว Y / หนาฐาน |
| `footing.depth` | ระยะจากระดับดินถึงท้องฐาน (ดูมิติรวมในรูปตัด เช่น 1000 = 750 + 250) |
| `cover` | ระยะหุ้มฐาน (ค่าปกติ 50 เมื่อเทบนคอนกรีตหยาบ, 75 เมื่อหล่อติดดิน) |
| `lean`, `sand` | ความหนาคอนกรีตหยาบ / ทรายบดอัด |
| `bars.x` = B1, `bars.y` = B2 | `n`, `type` (DB/RB), `dia` ตามที่แบบระบุ เช่น "10-DB12 B1" |
| `bars.ring` | เหล็กรัดรอบ ใส่เฉพาะเมื่อแบบมี (เช่น "RB9 รัดรอบ") ถ้าไม่มีให้ลบคีย์นี้ออก |
| `column` | ขนาดเสาตอม่อ, เหล็กยืน `main` (n = 4/6/8), ปลอก `tie`, `above_ground` (ระยะทาบเหนือดิน), `foot` (ขาเท้า) |
| `assumed`, `grade_assumed` | ตั้งเป็น `true` เมื่อค่านั้นไม่ได้มาจากแบบ |
| `count` | จำนวนฐานเริ่มต้น (ถ้าผู้ใช้บอกมา) |

แบบฐานรากมักไม่ระบุเหล็กเสาและชั้นคุณภาพเหล็ก ให้ใช้ค่าที่สมเหตุสมผล (เสาเล็ก 4-DB12 ปลอก RB6@0.15, SD40/SR24) แล้วตั้ง `assumed: true` ระบบจะติดป้าย "ตรวจตารางเสา" และขึ้นคำเตือนสีส้มในหน้าเว็บกับ Excel เพื่อให้ช่างไม่ตัดเหล็กจากค่าที่เดาไว้โดยไม่รู้ตัว ถ้าผู้ใช้มีตารางเสาให้ ให้ใช้ค่าจริงและตั้ง `assumed: false`

### 2. รัน generator
```bash
python3 <skill>/scripts/build_footing.py config.json --out <โฟลเดอร์งาน>/F1
```
จะได้ไฟล์ `index.html`, `<NAME>-bar-cutting-list.xlsx` และ `<NAME>-calc.json` และ script จะพิมพ์สรุปเหล็กทุก Mark กับคำเตือน (WARN) ออกมาด้วย ให้อ่าน WARN ทุกข้อ เช่น ขางอสั้นกว่า 12d, ระยะเรียงเกิน 300 มม. หรือยาวตัดเกินความยาวเหล็กเส้น ถ้าเกิดจากการอ่านแบบผิด ให้แก้ config แล้วรันใหม่

script ต้องใช้ `openpyxl` ส่วนหน้าเว็บโหลด three.js r128 จาก cdnjs

### 3. ตรวจและส่งงาน
- ดูภาพ Sheet 1 หนึ่งครั้งถ้าทำได้ เพื่อเช็กว่าป้ายไม่ทับกันและรูปตัดตรงกับแบบต้นฉบับ
- คัดลอกรูปแบบต้นฉบับไปไว้ในโฟลเดอร์เดียวกัน (เช่น `F1-original-design.jpg`) เพื่อใช้อ้างอิง
- เผยแพร่ `index.html` เป็น Artifact ถ้ามีเครื่องมือนี้ และส่ง Excel ให้ผู้ใช้
- สรุปให้ผู้ใช้เป็นตาราง Mark | ขนาด | รูปดัด | ยาวตัด | จำนวน | น้ำหนัก ตามด้วยน้ำหนักรวมต่อฐาน, จำนวนเหล็กเส้นที่ต้องสั่ง และ**ค่าสมมติฐานทุกข้อ**ที่ต้องตรวจก่อนตัดจริง

## วิธีคำนวณ (script ทำให้แล้ว เขียนไว้เพื่อตรวจและอธิบายให้ผู้ใช้ได้)
- **B1 (รูป U)**: ขางอ A = t − 2·cover, ช่วงตรง B = กว้างฐาน − 2·cover
- **B2**: วางทับ B1 จึงใช้ A2 = A − d(B1)
- **ยาวตัด** = ผลรวมระยะภายนอก − 2d ต่อมุม 90° แล้วปัดขึ้นทุก 10 มม.
- **ระยะเรียง**: เส้นแรกห่างขอบฐาน cover + 25 มม. แล้วแบ่งเท่ากันตามจำนวนเส้น
- **รัดรอบ**: ขนาด = กว้าง − 2·cover − 2·dmax − 6 (ปัดลงทุก 10 มม.), ยาว = เส้นรอบรูปที่แนวศูนย์กลาง + ทาบ 40d
- **เหล็กยืนเสา (รูป L)**: นั่งบนตะแกรงล่าง สูงถึงระดับดิน + `above_ground`, ขาเท้า ≥ 12d (ค่าเริ่มต้น 250)
- **ปลอก**: ขนาด = เสา − 2·cover เสา, ขอ 135° ยาว max(6d, 75); มี 1 ตัวในฐาน แล้วเริ่มที่ t + 50 เรียงตามระยะ s จนถึงระดับดิน + 50
- **แผนตัด**: แต่ละ Mark ใช้รูปแบบเดียวต่อเส้น (ได้ floor(10 ม. / ยาวตัด) ท่อน) เพราะช่างทำตามได้ง่ายที่สุด
- **น้ำหนัก**: ใช้ตาราง กก./ม. (DB12 = 0.888, RB9 = 0.499, RB6 = 0.222 …) ขนาดอื่นใช้ 0.00617d²

## เมื่อแบบต่างจากกรณีนี้
- **ฐานสี่เหลี่ยมผืนผ้า, จำนวนเหล็ก X/Y ไม่เท่ากัน, ไม่มีรัดรอบ, เสา 6/8 เส้น**: config รองรับอยู่แล้ว
- **ฐานไม่มีเสาตอม่อ** (เช่น ฐานรองถัง): ลบคีย์ `column` ออก
- **ฐานบนเข็ม, ฐานร่วม, มีเหล็กบน (T1/T2) หรือ Mark รูปแบบอื่น**: generator ยังไม่รองรับ ให้คัดลอก `assets/footing_template.html` ไปแก้ส่วน JS ที่วาดแปลน/รูปตัด/3D และเพิ่ม Mark ใน `compute()` ของ script ตามวิธีเดียวกัน โดยต้องให้ HTML กับ Excel ยังใช้ข้อมูลชุดเดียวกัน
- **หลายฐานในชุดแบบเดียว** (F1, F2, F3): เขียน config แยกทีละฐาน รันแยกโฟลเดอร์ แล้วสรุปรวมจำนวนเหล็กเส้นที่ต้องสั่งให้ผู้ใช้
