# ออฟฟิศสด (Live Office)

หน้าออฟฟิศสดแสดงการทำงานของทุกคนให้พี่โสภณเห็นแบบเหมือนจริง: ภาพห้องและคนที่กำลังรับคำสั่ง แจกงาน ส่งงาน แก้งาน ประชุม และรายงาน พร้อมกระดานสถานะของทั้ง 13 ตำแหน่งและบันทึกความเคลื่อนไหว

- ลิงก์ออฟฟิศสด: `OFFICE = https://claude.ai/artifact/T3Y4ExgDUtnezpzXhJxUJn`
  (พี่โสภณเปลี่ยนได้ โดยเขียน URL ใหม่ในไฟล์ `JOB/office_url` ของแฟ้มงาน)
- ข้อมูลอยู่ในฐานข้อมูลของหน้า collection `events` — เฉพาะพี่โสภณ (ในนามเลขา) เขียนได้ ผู้ชมอ่านอย่างเดียว
- ไม่มีงานจริง → หน้าจะเล่น "ตัวอย่างจำลอง" และติดป้ายไว้ชัดเจน

## หน้าที่ของเลขา
**ทุกครั้งที่เกิดจังหวะงานด้านล่าง** ให้สร้างเหตุการณ์ด้วย `office.py ev` (ได้หลายรายการ) แล้วส่งเป็นชุดด้วย `ArtifactData` (โหลดด้วย ToolSearch `select:ArtifactData` ถ้ายังไม่มี):

```bash
python SKILL/scripts/office.py ev JOB order "ถอดแบบบ้าน 2 ชั้น ทำ BOQ 6 งวด" --title "บ้าน 2 ชั้น คุณเอ"
python SKILL/scripts/office.py ev JOB assign "Wave A ถอดแบบ" --teams STR,ARC,MEP,PLN
python SKILL/scripts/office.py outbox JOB      # พิมพ์ JSON array ของ writes
```
แล้วเรียก `ArtifactData` `action: "batch"`, `url: OFFICE`, `writes: <JSON array ที่พิมพ์ออกมา>`
(ทุกรายการเป็นเอกสารใหม่ จึงไม่ต้องใส่ `if_version`) — ส่งไม่ได้ (ไม่มีสิทธิ์/เครือข่าย) ไม่ต้องหยุดงาน ให้แจ้งพี่โสภณ 1 บรรทัดและทำงานต่อ เหตุการณ์ยังค้างในคิวให้ส่งรอบถัดไป

ส่งทันทีที่เกิดเหตุการณ์ (ไม่ต้องรอจบงาน) เพื่อให้พี่โสภณเห็นสด ๆ — รวมหลายเหตุการณ์ที่เกิดพร้อมกันในชุดเดียวได้

## ชนิดเหตุการณ์ → สิ่งที่หน้าออฟฟิศแสดง
| ชนิด | ใช้เมื่อ | ตัวเลือก | ภาพที่แสดง |
|---|---|---|---|
| `order` | รับคำสั่งจากพี่โสภณ | `--title` ชื่องานสั้น | ห้องพี่โสภณ เลขารับคำสั่ง |
| `plan` | หัวหน้าวางแผนเสร็จ | | โต๊ะหัวหน้าทีม |
| `assign` | ส่งใบสั่งงานให้ฝ่าย | `--teams` | หัวหน้า/เลขาแจกงาน (ทีม Content/อบรม/โปรแกรมแสดงห้องของทีม) |
| `working` | ฝ่ายรายงานความคืบหน้า | `--team --pct` | วิศวกรกำลังทำงาน |
| `deliver` | ฝ่ายส่งงาน | `--team`, `--to HEAD` (ค่าเริ่มต้น) หรือ `--to SEC` สำหรับ CNT/TRN/DEV | ส่งแฟ้มงานให้หัวหน้า/เลขา |
| `review_pass` | หัวหน้าตรวจผ่าน | `--team`/`--teams` | |
| `review_fail` | หัวหน้าส่งกลับแก้ | `--team`, ข้อความ = สิ่งที่ต้องแก้ | หัวหน้าชี้จุดแก้บนจอ |
| `issue` | ฝ่ายพบปัญหาข้ามฝ่าย | `--team --with` | วิศวกรแจ้งปัญหาที่โต๊ะเลขา |
| `meeting_start` | เปิดประชุม (MTG-xxx) | `--teams`, ข้อความ = หัวข้อ | ห้องประชุม |
| `meeting_say` | ความเห็นของแต่ละฝ่ายในที่ประชุม | `--team` | ห้องประชุม |
| `meeting_end` | ได้มติ | ข้อความ = มติ + ผลกระทบ | ทีมตกลงกันได้ |
| `handover` | หัวหน้าสรุปส่งมอบให้เลขา | | หัวหน้าส่งรายงานให้เลขา |
| `report` | เลขารายงานพี่โสภณ | | เลขานำเสนอพี่โสภณ |
| `approval_request` / `approved` / `rejected` | ขออนุมัติโพสต์/งาน และผล | `--team CNT` | พี่โสภณพิจารณาบนแท็บเล็ต |
| `published` | โพสต์/เผยแพร่แล้ว | `--team` | สตูดิโอ Content |
| `done` | ปิดงาน | | |

รหัสตำแหน่ง: `CEO SEC HEAD STR ARC MEP PUR PLN BOQ CNT TRN WEB SKP` (`DEV` = WEB)

## ข้อความ
- สั้น 1 บรรทัด อ่านเข้าใจทันที มีตัวเลขเมื่อมี เช่น "คอนกรีต 64.2 ลบ.ม. เหล็ก 7.1 ตัน"
- ห้ามใส่ข้อมูลลับ ราคาที่พี่โสภณไม่อยากเปิดเผย ข้อมูลลูกค้า หรือรหัสผ่าน — ทุกคนที่พี่โสภณแชร์หน้านี้ให้จะเห็น
- `approved` ส่งได้เฉพาะหลังพี่โสภณอนุมัติในแชตจริงเท่านั้น

## ดูแลฐานข้อมูล
ความจุ 25,000 เหตุการณ์ เมื่องานเก่าเกิน ~5,000 รายการ ให้เสนอพี่โสภณลบเหตุการณ์ของงานที่ปิดแล้ว (ใช้ `ArtifactData` `delete` ทีละรายการพร้อม `if_version`)
