# ระเบียบการประชุมแก้ปัญหาระหว่างทีม

หลักการ: **ทีมที่เจอปัญหาประชุมแก้กันเอง** เลขาเป็นผู้นัด ส่งวาระ จดรายงาน และนำผลรายงานพี่โสภณ — เลขาและหัวหน้าไม่ตัดสินแทนทีม (หัวหน้าได้รับสำเนามติเพื่อปรับแผน)

## เมื่อไรต้องประชุม
- ปัญหามี `with` เป็นฝ่ายอื่น หรือ `need_meeting: "yes"`
- ตัวเลขของ 2 ฝ่ายขัดกัน (เช่น ARC ถอดผนังซ้อนกับ STR, MEP ท่อชนคาน, PUR หาวัสดุตามสเปคไม่ได้, PLN ระยะเวลาไม่พอกับกำหนดส่ง)
- หัวหน้าตรวจแล้วพบปัญหาข้ามฝ่าย
- ปัญหาหลายข้อที่ฝ่ายเดียวกันเกี่ยวข้อง → รวมเป็นการประชุมเดียว (หลายวาระ)

## ขั้นตอน (สูงสุด 3 รอบ)
1. **เลขาเปิดรายงานการประชุม** `JOB/meetings/MTG-xxx.md` จากแม่แบบด้านล่าง ใส่วาระ ข้อเท็จจริง ผู้เข้าประชุม และลงทะเบียนใน `issues.md` สถานะ "นัดประชุม"
2. **รอบที่ 1 — แต่ละฝ่ายเสนอความเห็น**: เรียก agent ของทุกฝ่ายที่เข้าประชุมพร้อมกัน ใบสั่ง:
   ```
   ตำแหน่ง: <ฝ่าย> | เข้าประชุม MTG-xxx | SKILL=... JOB=...
   อ่าน JOB/meetings/MTG-xxx.md แล้วเขียนความเห็นของฝ่ายคุณใต้หัวข้อ "รอบที่ 1 / <ฝ่าย>":
   ข้อเท็จจริงจากงานของคุณ (อ้างแผ่นแบบ/ตัวเลข), ข้อเสนอวิธีแก้, ผลกระทบต่องานของคุณ, สิ่งที่ต้องการจากฝ่ายอื่น
   ห้ามแก้ข้อความของฝ่ายอื่น
   ```
   (ถ้า agent ของฝ่ายจาก wave ก่อนยังอยู่ ใช้ SendMessage เพื่อคงบริบท)
3. **รอบที่ 2 — หาข้อสรุป**: ส่งให้ทุกฝ่ายอ่านความเห็นรอบ 1 ของกันและกัน แล้วเขียน "ตกลง/ไม่ตกลง + ข้อเสนอสุดท้าย"
4. **ได้มติเมื่อ** ทุกฝ่ายตกลงข้อเสนอเดียวกัน → เลขาเขียนหัวข้อ "มติที่ประชุม" (ใครแก้อะไร ภายในเมื่อไร ผลกระทบราคา/เวลา)
5. **รอบที่ 3 (ถ้ายังไม่ตกลง)**: เลขาสรุปทางเลือกที่เหลือเป็นตาราง ให้แต่ละฝ่ายให้คะแนน/เหตุผลอีกครั้ง ยังไม่ตกลง → ยกเป็น "เรื่องรอพี่โสภณตัดสิน" พร้อมทางเลือกและข้อเสนอเสียงข้างมาก
6. **ปฏิบัติตามมติ**: เลขาส่งงานแก้ให้ฝ่ายที่ต้องแก้ (ตามมติ) → ฝ่ายแก้แล้วยืนยันในรายงานการประชุม "ดำเนินการแล้ว"
7. **ส่งสำเนามติให้หัวหน้า** (ไม่ต้องเรียก agent แยก — แนบไปกับการ REVIEW รอบถัดไป หรือ CHANGE ถ้ากระทบแผน)
8. **รายงานพี่โสภณผ่านเลขา**: ปัญหาที่แก้แล้วรวมใน `99_report_to_sophon.md` ส่วน "ปัญหาที่พบและวิธีแก้" ถ้าเป็นปัญหาใหญ่ (กระทบมูลค่า > 5% หรือกระทบกำหนดส่ง) แจ้งพี่โสภณทันทีในแชต 2-3 บรรทัด ไม่ต้องรอจบงาน
