# มาตรฐานงานของทีม (ทุกฝ่ายใช้ร่วมกัน)

## รหัสรายการและคีย์ราคา
- id รายการ: `<ฝ่าย>-<หมวดย่อย 2 หลัก>-<ลำดับ 3 หลัก>` เช่น `STR-02-001`, `ARC-05-012`, `MEP-EE-004`
- คีย์ราคา (`price_key`): ตัวพิมพ์ใหญ่ คั่นด้วย `-` บอกวัสดุและขนาด เช่น `CONC-240`, `STEEL-DB12`, `BRICK-LIGHT-7.5`, `PVC-13.5-1/2`, `WIRE-THW-2.5`, `AC-WALL-12000`
- รายการที่ใช้วัสดุเดียวกันต้องใช้คีย์ราคาเดียวกันทุกฝ่าย (คีย์ใหม่ให้แจ้งใน report.md)

## หน่วยมาตรฐาน
คอนกรีต ลบ.ม. • เหล็กเสริม กก. (แยก RB/DB ตามขนาด) • แบบหล่อ ตร.ม. • ผนัง/ฉาบ/สี/พื้น/ฝ้า ตร.ม. • บัว/คิ้ว ม. • ประตูหน้าต่าง ชุด • ท่อ/สายไฟ ม. • อุปกรณ์/สุขภัณฑ์ ชุด/จุด • แอร์ ชุด (ระบุ BTU) • หลังคา ตร.ม. (พื้นที่ลาดเอียง)

## อัตราส่วนตรวจความสมเหตุสมผล (บ้าน/อาคาร คสล. ทั่วไป)
- เหล็กเสริม ≈ 90–140 กก./ลบ.ม. คอนกรีต
- แบบหล่อ ≈ 6–10 ตร.ม./ลบ.ม. คอนกรีต (ไม่รวมพื้นสำเร็จ)
- ฉาบ ≈ 2 เท่าของพื้นที่ผนังก่อ (ฉาบ 2 ด้าน) หักช่องเปิด
- สีภายใน ≥ พื้นที่ฉาบภายใน + ฝ้าที่ทาสี
- ค่าก่อสร้างรวม บ้านพักอาศัยทั่วไป ≈ 12,000–25,000 บาท/ตร.ม. พื้นที่ใช้สอย (นอกช่วง → ต้องอธิบาย)
- สัดส่วนโดยประมาณ: โครงสร้าง 25–35% • สถาปัตย์ 40–50% • งานระบบ 15–25%

## ราคา
- ราคาต่อหน่วยแยก **ค่าวัสดุ** และ **ค่าแรง** เสมอ
- ลำดับแหล่งราคา: Vendor List ของพี่โสภณ → ตารางราคาบริษัท → เว็บร้านค้า/ผู้ผลิต (อย่างน้อย 2–3 แหล่งสำหรับรายการมูลค่าสูง) → ราคาประมาณการ (ติดธง `confidence: ต่ำ`)
- ทุกราคามีวันที่และแหล่งที่มา ราคาเก่ากว่า 90 วันต้องระบุ
- ค่าเริ่มต้น: ราคาไม่รวม VAT แสดง VAT 7% แยกบรรทัด ไม่ใส่ Factor F ถ้าพี่โสภณไม่สั่ง

## ผลงาน Excel
- ทุกตัวเลขใน BOQ ลิงก์สูตรมาจาก Backup และตารางราคา (ไม่พิมพ์ทับค่า)
- ชีตขั้นต่ำ: สรุป, BOQ, Backup (แยกหมวด), ราคา, แผนงาน (Gantt), S-Curve, งวดงาน
- ตั้งหน้ากระดาษ A4 พิมพ์ได้ หัวกระดาษชื่องาน/วันที่
